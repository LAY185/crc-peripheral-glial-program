# Version 1.0.0

This release accompanies the manuscript "Cross-platform transcriptomics identifies a recurrent tumour-associated peripheral-glial module in colorectal cancer."

It contains the locked analysis scripts, fixed 33-gene perturbation program, fixed 13-gene cross-platform scaffold, three-gene human module, panel-level source data, key intermediate tables, and commands that regenerate the main and supplementary figures.

The archive excludes downloaded raw datasets, CRC Atlas caches, local paths, credentials, manuscript drafts, QA renders, and exploratory figure versions.
