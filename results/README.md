# Results and source data

`source_data/` contains the panel-level values underlying Fig. 1 to Fig. 4 and Supplementary Fig. S1 to Fig. S2. `source_data_manifest.csv` maps every panel to its source file and generating script.

`tables/` contains the analysis outputs required to regenerate the final figures and inspect the reported statistical tests. Large public raw datasets and CRC Atlas API caches are intentionally absent.

`manuscript_figures/` contains the final PNG, PDF, and SVG exports for Fig. 1 to Fig. 4 and Supplementary Fig. S1. `figures/` contains Supplementary Fig. S2.
